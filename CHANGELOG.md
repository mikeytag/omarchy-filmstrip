# Changelog

## 0.1.5

- Show only alternative windows in the sidebar; hide and stop capturing the main window's redundant preview.
- Keep all windows in keyboard cycling and retain single-window expansion.

## 0.1.4 — First public release

- Native monocle layout prevents clicks and hover from reaching inactive windows.
- A 10% sidebar shows real, clickable window captures and follows Omarchy themes.
- Per-workspace layout toggling and stable window cycling.
- Automatic sidebar hiding for a single tiled window and fullscreen.
- Optional header/footer text and configurable background opacity.
- Installer for Omarchy's Lua/Quickshell configuration with backups, dry-run,
  repeatable installation, and guarded rollback.
- Installer tests and live pointer/click regression tools.
